# 管理面與稽核

管理面是管理員專用的區域。它管帳號、專案與憑證，不碰規格內容。每一個管理動作都留下一筆稽核紀錄。

## 誰能進

- 你必須已登入，而且帳號帶 admin 旗標。
- 未登入呼叫管理 API：401。
- 已登入但不是 admin：403 permission_denied。畫面顯示無權限狀態，不執行任何管理動作。
- 被停權的 admin，在下一個請求就失去通行。
- 從不同來源網站送出的管理動作一律 403，不執行也不留成功的稽核紀錄。

## 三個入口，同一份實作

管理動作可以從三個地方做，行為相同：

- 瀏覽器後台（來源記為 `web`）。
- API（來源記為 `api`）。
- server 的 CLI 子命令（來源記為 `cli`）。沒有瀏覽器的部署靠這條路。

功能集：

- 使用者列表與邀請。
- 停權與復權。
- 成員資格與 admin 旗標的調整。
- 專案與儲存庫的建立與顯示名變更。代號不可改。
- 全站憑證的檢視與強制撤銷。

會擋下的情況：

- 停權最後一位啟用中的 admin：拒絕，並明示原因。server 回給後台的使用者清單也會標示這個人不可停權、不可移除 admin 旗標；server 送出動作時仍會再檢查一次。
- 管理面沒有規格內容（變更、規格、討論）的檢視或編輯。那些在桌面 app 與 CLI。

## 憑證只能監督，不能讀回

- 憑證頁只有這些資訊：所屬使用者、開頭幾碼、名稱、到期、上次使用、建立時間。
- 沒有任何介面能讀回存取金鑰、通行證或續約憑證的明文或雜湊。
- 強制撤銷與使用者自助撤銷一樣即時生效。撤銷後那把憑證的下一次使用回 401。
- 強制撤銷記入稽核紀錄，含操作者與憑證識別，不含祕密值。

## 稽核紀錄

- 每筆記錄含：操作者、動作種類、對象、UTC 時間、來源（`web`、`api`、`cli`）。
- 每一個變更型管理動作恰寫一筆，與資料變更在同一個交易裡。動作失敗就沒有記錄；有記錄就代表動作生效了。
- invite 子命令與開箱流程的建立動作也算在內。
- 稽核紀錄只增不改。沒有更新或刪除的介面。
- 在 `/admin` 的稽核頁唯讀、由新到舊。一般使用者看不到。

篩選稽核紀錄時，關鍵字、動作、來源、時間區間、頁碼與每頁筆數都交給 server 計算。server 回當頁事件、總頁數，以及符合篩選的總筆數。總筆數只看篩選條件，與頁碼、每頁筆數無關。

例：由新到舊有五筆事件，其中三筆是邀請。每頁 2 筆、只篩邀請、看第 2 頁：回 1 筆事件，總頁數 2，總筆數 3。

| 情況 | 結果 |
| --- | --- |
| 頁碼是 0 或負數 | 400，不回事件 |
| 頁碼大於總頁數 | 空清單，總頁數與總筆數照實回，不回 404 |
| 動作名稱不存在 | 空清單，總頁數 0，總筆數 0 |
| 時間區間起始晚於結束 | 400 |
| 不帶任何篩選 | 第一頁全部事件、總頁數與全部事件的總筆數 |

## 系統頁

系統頁唯讀，一次顯示四組資料：

- 執行環境：引擎與 API 版本、資料結構版本。
- 儲存後端：驅動、契約版本、等級、能力、健康檢查的即時結果、每個 scope 的待送佇列。
- 可匯出的 scope 清單。
- 資料結構遷移是否可用。

儲存後端失聯時：

- 系統頁如實顯示健康檢查失敗，其餘資訊照常顯示。頁面不會整個壞掉。
- 使用者與憑證的管理照常可用。例如停權一個使用者照常成功，並記入稽核紀錄。
- 總覽頁也會顯示儲存後端不健康與可公開的錯誤原因。

系統頁的匯出、備份資訊與遷移操作見 [備份與還原](server-backup.md)。畫面的細節見 [瀏覽器後台](web-console.md)。
