# 公司 Proxy 實機驗收

狀態：尚未執行，任務 12.3 保持未完成。

交付順序：功能分支完成實作及合併前必要檢查 → 合併回本專案 main → 從 main 的明確 commit 打包產生安裝檔 → 公司環境安裝驗收。合併時不代勾 12.3，也不將合併當成封存完成。

2026-10-21 使用者調整：公司只能使用打包安裝版本，故開發測試期間先跳過；待安裝檔交付後才進公司測試。公司外網的 npm run dev:desktop 測試不代替本項。延期不阻擋繼續實作與產生測試安裝檔，不記為通過，也不變更正式品質或封存守門。

目前只有本機模擬 Proxy／TLS／407／解析失敗與更新頁內附資料測試。這些結果不能證明公司實際網路可用，也無法判定公司端根因。

實機操作時請填寫：

- Desktop 版本與作業系統。
- 打包來源 main commit 與安裝檔名稱。
- Proxy 模式（系統／手動／直接）；不要記錄帳密或含機密參數的 URL。
- 版本與更新日誌是否在無網路時仍可查看。
- 手動檢查、下載的結果與顯示狀態；若本分支只提供未簽章安裝檔，記錄手動 Release 入口，不停用驗簽來通過測試。
- 遮罩後的 operationId 與錯誤分類；有失敗時保留具體現象。

完成後才可由實際操作者確認手動任務；尚未宣稱公司環境已修復。
