# 規格、討論、已封存與搜尋

看板以外，桌面 app 還有四個閱讀面：規格頁、討論詳情面板、已封存頁與手冊頁。這一頁講前三個怎麼呈現、怎麼搜尋、怎麼換頁，以及變更文件在詳情面板裡的中文標籤與色標。手冊頁另見[桌面 app 的手冊頁](desktop-manual.md)。這些畫面都是唯讀的。

## 規格頁

點側欄的「規格」進入規格頁。頁面以卡片清單列出全部正典規格。

每張規格卡在收合狀態就顯示：

- 規格名稱，後面緊跟複製名稱鈕（點它把名稱寫進剪貼簿並短暫顯示已複製）。
- 需求數、溯源變更數（以「圖示＋數字」呈現）。
- 最後修改的相對時間（今天／昨天／N 天前）。取不到修改時間時這項缺席。
- Purpose 摘要：正典 Purpose 段落的第一個非空行，一行截斷。Purpose 還是封存流程產生的佔位文字時，卡片改以警示樣式顯示「Purpose 待補」。

搜尋列以名稱子字串即時過濾，不分大小寫。清空輸入後清單還原。

| 既有規格 | 輸入 | 顯示 |
| --- | --- | --- |
| desktop-app、desktop-config、node-sdk | desktop | desktop-app、desktop-config |
| desktop-app、desktop-config、node-sdk | SDK | node-sdk |
| desktop-app、desktop-config、node-sdk | zzz | 無結果空狀態 |

點規格卡開啟唯讀的規格詳情面板，顯示該規格 `spec.md` 的全文與溯源資訊。詳情面板寬度與全螢幕切換和變更詳情面板一致；開著時內容隨外部檔案變更反映。清單卡片不提供行內展開。

清單依最後修改時間新到舊排序；取不到修改時間的規格排最後，並依名稱字母序排列。超過 20 筆時每頁 20 筆換頁（規則見下方「換頁」）。沒有任何規格的專案與搜尋無結果各有空狀態文案。規格頁不提供任何規格寫入操作。

> [!NOTE]
> 規格對「點規格卡之後」有兩種說法：較早的版本說卡片標題就地展開全文、下方帶一行來源變更；較晚的版本說開啟規格詳情面板、清單不提供行內展開。本頁依較晚的版本撰寫，詳見[本手冊的來源](about.md)。

## 變更文件的呈現

變更詳情面板與已封存詳情面板的提案、設計、規格分頁，用同一套渲染規則。

**提案與設計的章節標籤**：模板的英文章節標題呈現為中文標籤區塊，英文標題不直出。標籤為粗體大標題，字級大於內文的 16px。

| 來源章節標題 | 呈現標籤 |
| --- | --- |
| Why | 為什麼 |
| What Changes | 變更內容 |
| Non-Goals | 非目標 |
| Capabilities | 能力 |
| Impact | 影響 |
| Context | 背景 |
| Decisions | 決策 |
| Risks / Trade-offs | 風險與取捨 |

白名單以外的章節標題（例如設計裡自訂的決策小標）照一般 Markdown 標題呈現，不翻譯。整份文件沒有任何白名單章節時，整篇以一般 Markdown 檢視呈現，不報錯。

**規格分頁的 delta 色標**：delta 規格的區段標題呈現為色標區段標頭，原始英文標題不直出。區段內的需求與情境照一般排版呈現。不含 delta 區段標題的規格文件整篇照常渲染。

| 來源區段標題 | 標頭文字 | 色系 |
| --- | --- | --- |
| ADDED Requirements | 新增 | 綠 |
| MODIFIED Requirements | 修改 | 琥珀 |
| REMOVED Requirements | 移除 | 紅 |
| RENAMED Requirements | 更名 | 藍 |

渲染不會改任何來源檔案。

## 討論詳情面板

點看板討論欄的討論卡或已轉出細列，開啟討論詳情面板。詳情面板開啟時底層頁面切回看板。

**標頭**：標題是討論 slug（等寬字型），旁邊有複製 slug 鈕；topic 是標題下方的副標。標題區下方是生命週期階梯「討論中 → 已結論 → 轉出變更」，目前所在的站可辨識。改進討論的詳情面板帶「改進討論」標示。

**分頁**依序為：結論、討論過程 N、背景、衍生變更。

- 記錄切分成功且結論非空時，預設開在「結論」；結論為空時預設開在「背景」。
- 記錄的區段缺失或格式不符預期時，整篇以單一檢視呈現，不報錯。
- 「衍生變更」列出這份討論轉出的每個變更的現況，並可跳轉。這個分頁是唯讀的，沒有「轉為變更」或「再轉出一個變更」按鈕。

**討論過程的輪卡片**：符合工具產生格式的記錄，每一輪呈現為一張卡片。卡頭顯示輪次、模式與日期。卡身把行首的 Focus、Position、Ruled out、Open 前綴呈現為欄位標籤區塊，前綴原文不出現；一個欄位涵蓋從標籤行到下一個標籤行的全部內容，列表符號保留。來源沒有的欄位不渲染空標籤。任一輪的標題不符格式時，整篇退回一般 Markdown 檢視，不報錯。記錄裡由 CLI 產生的 HTML 註解不會顯示。

**結論的欄位標籤**：行首的 Decision、Rationale、Rejected alternatives、Deferred、Capture to、Next 前綴呈現為標籤區塊，中文介面依序為決定、理由、否決替代案、擱置、記錄去向、下一步。來源沒有的欄位不渲染空標籤。結論不含任何這六個前綴時，整篇退回一般 Markdown 檢視。

**封存討論**：已結論且未封存的討論，在討論卡與討論詳情面板都有封存動作，兩處走同一個確認流程。確認後討論移入封存，從討論欄消失、出現在已封存頁的討論節。未結論或已封存的討論，詳情面板不顯示封存動作。

> [!NOTE]
> 討論詳情面板不提供新增討論、加輪、寫結論、丟棄、轉為變更。這些由 CLI 或 agent 執行，見[討論：需求還模糊時](discuss.md)。

## 來源討論與同源變更

由討論轉出的變更，卡片帶一枚討論徽章。變更連結多份討論時，徽章仍只有一枚，代表清單第一份（出身）討論；指標停留時列出全部來源討論。

在變更詳情面板：

- 出身列固定顯示第一份來源討論的籤，其餘收進「+N」籤（N 是未直接顯示的數量）。
- 點「+N」開啟浮層，列出其餘來源討論的 slug 與 topic。點任一項開啟該討論的詳情面板。
- 只有一份來源討論的變更沒有「+N」籤。
- 來源討論籤以 slug 直出（等寬字型），topic 不直出。slug 超過寬度上限時截斷，指標停留顯示完整 slug 與 topic。多份來源討論不會各自換行。

**同源變更**：兩個變更的來源討論集合有交集，就互為同源。同源變更清單也是顯示第一顆、其餘收「+N」浮層，點浮層項開啟該變更的詳情。

| 變更 A 的來源 | 變更 B 的來源 | 是否同源 |
| --- | --- | --- |
| d1, d2 | d2 | 是 |
| d1 | d1 | 是 |
| d1, d2 | d3 | 否 |
| （無） | d1 | 否 |

已封存詳情面板適用同樣的規則。

## 已封存頁

點側欄的「已封存」進入已封存頁。頁內有「變更」「討論」兩個子頁籤，預設顯示「變更」。每個子頁籤標籤帶一枚徽章，顯示該節目前（搜尋過濾後）的筆數。

**搜尋**：搜尋框在子頁籤之上，同時過濾兩節。你在任一子頁籤時，另一個子頁籤的徽章反映它的命中數。搜尋字串與看板的搜尋各自獨立。

**卡片**：

- 封存變更卡顯示封存日期、變更名（緊跟複製鈕，複製的是含日期前綴的封存目錄名）、任務數徽章、觸及規格數、建立者標記（指標停留顯示全名）、來源討論標記（無來源討論時缺席）。標題下方一行截斷顯示提案「為什麼」的首句；取不到時整張卡退回單行。任務未全完成的徽章以警示樣式呈現，與全完成可一眼區辨；沒有 `tasks.md` 的變更不顯示徽章。
- 封存討論卡以 slug 為標題（等寬、緊跟複製 slug 鈕），topic 降為標題下方的描述列，並顯示日期、輪數與衍生變更數。改進討論仍帶「改進討論」小章。

**排序**：封存變更依封存日期新到舊（同日依封存目錄名降冪）；封存討論依建立日期新到舊（同日依 slug 升冪）。

**唯讀詳情面板**：點卡片開啟唯讀詳情面板，清單卡片沒有行內展開。

- 封存變更詳情面板至少有提案、設計、任務、規格分頁，內容來自封存目錄的實體文件。任務分頁的核取方塊不可點、沒有工具列、沒有拖曳把手。所請求的文件不存在時，該分頁顯示空狀態而非錯誤。
- 有來源討論的封存變更，標題下方有可點的來源討論標記。點它在同一個詳情面板切換到該討論的唯讀檢視；記錄優先讀進行中的版本，讀不到再讀封存版本。
- 封存討論詳情面板呈現「背景」「討論過程」「結論」三個區段，輪卡片與結論標籤的規則與討論詳情面板相同。
- 兩種詳情面板的標頭：標題後緊跟複製鈕；標題之下是出身列，顯示建立者（首字母圓標＋名字，完整識別收進指標停留提示）、建立日期與封存日期，單行、溢出裁切。缺席的欄位整段不顯示。標頭沒有進度條與動作列，封存是唯讀定格。
- 詳情面板開著時內容隨外部檔案變更反映。寬度與全螢幕切換和變更詳情面板一致。

已封存的變更在清單與詳情面板上會帶審查與驗證的結局標示，見[桌面上的品質關卡](desktop-quality.md)。

隨最後一個子變更封存而自動封存的討論，與用桌面或 CLI 手動封存的討論，一致地出現在討論節。已封存變更的清單資料有一份本地快取。這份快取是衍生資料：刪掉會自動重建，與檔案不一致時以檔案為準。進行中的變更與規格清單不用這份快取，一律即時讀檔。

## 換頁

規格頁與已封存頁的清單每頁 20 筆。

- 頁面填滿視窗高度，頁面本身不縱向捲動；搜尋框（與已封存頁的子頁籤列）固定在頂部，卡片清單在內部容器捲動。
- 過濾後超過 20 筆時，換頁控制列（上一頁鈕、目前頁與總頁數、下一頁鈕）固定在頁面底部，不捲動也能換頁。第 1 頁時上一頁不可用，末頁時下一頁不可用。
- 過濾後 20 筆以內沒有換頁控制列。
- 改搜尋字串會回到第 1 頁。換頁後內部捲動容器捲回頂部。清單縮短使目前頁碼越界時，跳到末頁而不是顯示空頁。
- 已封存頁「變更」「討論」兩個子頁籤的頁碼各自獨立。

排序與換頁只影響呈現，不改變清單的載入方式。
