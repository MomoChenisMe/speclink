# Claude Code：查看進度與工單

Speclink 側邊面板讓你在 Claude Code 對話內查看變更、討論與品質工單，點名稱後再自行送出技能指令。面板查詢資料，不代替實作、蓋章或封存。

## 開啟與選名稱

點面板按鈕，或送出 `/speclink-panel`，可在開啟與關閉間切換。繁中回應分別是「speclink 面板已開啟。」與「speclink 面板已關閉。」。

點變更、下一步、討論或工單名稱，會把名稱填成輸入框最前方指令的參數。例如 `/speclink-apply old-one` 點 add-auth 後變成 `/speclink-apply add-auth`。沒有指令時，名稱接在現有文字後面。點擊不會自動執行或修改文件。

## 看板：下一步與任務

面板依執行計畫顯示下一步、波次、階段與等待的前置，變更分成提案中、進行中、已就緒，各區塊可收合。任務進度與 worktree 資訊來自變更清單。

展開變更可看文件是否完成與分組的任務，完成與未完成分開顯示，手動項目標為「手動」。有 worktree 時，讀取該 worktree 的內容。執行順序的意義見 [plan 與依賴](plan.md)。

## 討論與品質

討論分頁排除已轉出的討論，分開呈現討論中與其餘討論。討論中顯示輪數，已結論顯示已結論。展開可讀內文，文件開頭的附帶資訊與註解不顯示。

品質分頁列出有審查或驗證工單的變更，只取各工單最後一輪，顯示輪數與各嚴重度數量。展開可讀嚴重度、路徑與發現文字。沒有工單與查詢失敗會分開呈現；不能把讀取錯誤當成沒有問題。品質流程見 [品質關卡總覽](quality-stations.md)。

## 重新整理與失敗

開啟面板時會查資料；重新整理、每輪完成與 Speclink 指令結束時，也會更新已開啟的面板。展開中的變更與討論會重讀，品質分頁開啟時會重讀工單。

看板查詢失敗會保留上一份資料，顯示錯誤與 CLI PATH 提示；第一次查詢失敗則顯示錯誤，不假裝成功讀到空清單。詳情錯誤顯示在展開列；品質讀取失敗保留原品質資料。錯誤沒有文字時顯示結束碼。

若提示找不到 CLI，先讓目前執行面板的環境能執行 `speclink`。remote 離線或認證失效時，面板沿用查詢錯誤顯示，不會把資料寫回本機或另做登入與覆寫。
