# 安裝與管理安全標準資料

先在[產出政策](policy-config.md)選擇要用的標準與版本，再明確安裝資料。資料裝好後，標準查詢、基本規則審查及報告都能離線執行。資料放在應用程式資料目錄，Desktop 與 CLI 共用，不寫入任何受檢專案。

## 在桌面 app 安裝

1. 點圖示列齒輪，進入應用程式設定。
2. 選「安全標準資料」。沒有開啟專案時也能進入。
3. 查看所需標準的可用版本、安裝狀態、來源、授權及署名，再按下載。
4. 等待下載及解析結束，確認所選版本已安裝，再到[執行初步安全審查](security-review.md)。

只選 Top 10 2025，就只需為該標準安裝資料；不必為了它再安裝 ASVS 或 CWE。標準版本各自獨立，ASVS 4.0.3 與 5.0.0 的要求及等級也按各自版本解讀。

下載或重新下載後，當次標準及版本的按鈕立即顯示「下載中」。例如 API 2019 正在下載時，2019 顯示「下載中」，2023 仍顯示「下載」但不能按。畫面另有階段、資料量、檔案數與取消操作；取消或失敗後按鈕還原，不會冒稱已安裝。

## 更新清單、重裝與取消

- 更新版本清單只在你明確操作時連線；未知格式或不支援的新版本不能下載。
- 來源只限核准的 OWASP 官方資料與 MITRE 固定版資產，不接受任意下載網址。
- 版本不符、格式錯誤、授權缺失或資料超大時，顯示原因並拒絕安裝。
- 下載及匯入只在驗證完成後切換成新資料；提交前失敗或取消，舊版本仍可離線使用。
- 新資料已安裝、但清理暫存失敗時，結果會明示已安裝並附清理警告，不會說成安裝失敗。
- 同一版本正由另一個程序處理時，第二個操作會顯示忙碌，請等它結束。

Desktop 可按取消，CLI 可按 Ctrl+C；取消應在兩秒內結束，未完成版本不會成為可用資料。單次下載上限64 MiB、解壓總量256 MiB、最多128個項目、工作上限120秒，超限會中止並保留舊資料。

## 沒有網路時匯入

在此頁選離線包匯入，提供符合 SpecLink 離線包格式的 ZIP。一般文件壓縮檔不等於有效離線包；包內版本、內容指紋、結構與授權都要符合要求。越出目錄的路徑、連結、可執行檔、重名檔案或不安全的 XML 會被拒絕。

匯入成功後可離線查詢及使用。來源會標為匯入；包內自填的雜湊不能當成官方來源證明。實際授權、署名與解析修改說明仍會保留，不會被改成 SpecLink 程式碼的授權。

## 刪除未使用版本

刪除前會檢查執行中的審查、本機已知專案政策及準備快照。使用中的版本不能刪，畫面會說明原因。檢查不涵蓋所有尚未開啟的遠端專案；之後若另一個專案需要已刪的版本，會顯示資料缺失，不會自動下載或改掉政策。舊報告仍保留當時的版本及來源資料。

## CLI 操作

```sh
speclink security data list
speclink security data refresh
speclink security data install owasp_top10 --version 2025
speclink security data install owasp_top10 --version 2025 --reinstall
speclink security data import OFFLINE_PACKAGE.zip
speclink security data remove owasp_top10 --version 2025
```

把離線包檔名換成你自己的檔案。列清單不連網；更新清單及安裝才明確連官方來源。成功結束碼為0，失敗為1，取消為130，指令語法錯誤為2；錯誤與進度不混進資料輸出。需要機器可讀輸出時，在對應指令加 `--json`；不想要終端色彩時加 `--no-color`。

> [!NOTE]
> 審查發現缺資料時，只提供前往資料管理的操作，不會在背景下載。安裝資料也不代表專案通過安全審查。
