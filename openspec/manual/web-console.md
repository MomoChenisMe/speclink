# 瀏覽器後台

server 自帶一個瀏覽器後台。管理員在這裡管帳號、專案與憑證；一般成員在這裡管自己的帳號。後台不顯示規格內容：變更、規格、討論都在桌面 app 與 CLI。

## 有哪些頁

- 未登入的流程頁：`/setup`（開箱）、`/invite/<token>`（接受邀請）、`/login`（登入）、`/activate`（裝置核准）。
- 登入後：`/account`（帳號頁）與 `/admin`（管理面）。
- 管理面有六個目的地：總覽、使用者、專案與儲存庫、憑證、系統、稽核紀錄。側欄沒有獨立的資料操作項目，匯出與資料結構遷移都在系統頁。
- 帳號頁不在側欄。從 header 上顯示你 email 的連結進入，旁邊就是登出。
- 管理員開 `/account`：側欄六個目的地維持可見，沒有項目高亮。
- 一般成員開 `/account`：沒有側欄。頁面顯示帳號、存取金鑰、登入工作階段與裝置資訊。
- 每一頁都可以直接開啟或重新整理。例如直接開 `/admin/audit`，後台檢查登入狀態後顯示稽核紀錄頁。

## 登入後去哪

後台照 server 的裁決導向，不自己猜。順序是：

1. 網址帶有效的裝置碼：先顯示裝置核准流程。
2. 網址帶安全的返回路徑：只接受以 `/account`、`/activate` 或 `/admin` 開頭的站內路徑。
3. 都沒有：回角色首頁。

會擋下的情況：

- 返回路徑指向外部網站：後台不導向外部，改回角色首頁。
- 一般成員以 `/admin` 為返回路徑：顯示無權限狀態，不會退回 `/account`。
- 已開的頁面呼叫 API 收到 401（登入過期）：回到 `/login`，只保留安全的當前路徑。

## 管理列表怎麼操作

管理面的列表頁都用同一套操作方式：

- 列表是主體。表格列裡沒有輸入框、下拉或按鈕。
- 點整列開啟右側的詳情面板。窄螢幕時面板改為全寬。
- 建立、邀請、加入類動作由頁首唯一的主要動作開啟面板。表單不常駐在頁面上。
- 建立入口常駐頁首，不會因為清單非空而消失。
- 邀請時選要加入的專案：用下拉逐一挑選，已選的專案列在下方，可逐一移除。
- 面板內提交失敗：面板保持開啟，保留你輸入的非祕密內容，錯誤放在對應欄位附近。
- 面板內提交成功：面板關閉，列表更新，畫面回饋一則訊息。
- 只顯示一次的祕密（存取金鑰明文、邀請）附複製動作。邀請以受邀者可直接開啟的連結呈現，不只給一串 token。
- 破壞性操作送出前會出確認框，顯示確切對象。這包括停權、撤銷憑證、移除成員資格、刪除專案、資料結構遷移、撤回邀請。
- 請求進行中時，確認按鈕停用並顯示進度。第二次按不會重複送出。

## 搜尋、篩選與換頁

| 頁面 | 工具列 |
| --- | --- |
| 使用者 | 關鍵字搜尋、狀態篩選 |
| 專案與儲存庫 | 關鍵字搜尋 |
| 憑證 | 存取金鑰與裝置兩個分頁；關鍵字搜尋、狀態篩選 |
| 稽核紀錄 | 關鍵字搜尋、動作篩選、來源篩選、時間區間、換頁控制項 |

- 稽核紀錄的篩選與換頁由 server 計算。畫面只顯示 server 回的當頁事件與總頁數。
- 列表為空時，頁面說明這種資料的用途，不只寫一行「尚無資料」。
- 篩選沒有結果時，頁面顯示空狀態說明並保留篩選控制項。

## 使用者頁

- 每一列顯示：使用者、狀態、角色、成員資格、建立日期。
- 點一列開詳情面板：概要、成員資格、憑證、稽核。成員資格可在面板內新增與移除。
- 待啟用邀請另有一個區塊，列出還沒被接受的邀請：受邀者 email、顯示名稱、角色、要加入的專案、到期時間。
- 待啟用邀請可撤回。確認框指名受邀者。撤回後連結立即失效，那筆離開區塊，並留下一筆稽核事件。
- 已接受的邀請不能撤回。它背後已有真實帳號，要走停權。
- 沒有任何待啟用邀請時，區塊不顯示。

## 專案與儲存庫頁

- 專案代號與儲存庫代號建立後不可變更。面板以唯讀文字呈現，並標示建立後不可變更。畫面上沒有可編輯代號的輸入框。
- 專案名稱與儲存庫名稱預設也是唯讀文字。按「更名」後才出現輸入框，附確認與取消。

## 總覽

- 四張指標卡：使用者、專案、憑證、待啟用邀請的計數。點卡片前往對應頁面。
- 系統健康摘要，含資料結構版本，附前往系統頁的入口。
- 最近稽核事件，附前往稽核紀錄的入口。
- 有待處理事項時才顯示待辦區塊。每則待辦附處理入口。例如系統沒有任何有效憑證時，待辦提供建立存取金鑰的入口。

## 首次進入的導覽

- 第一次開管理面時，後台自動啟動分步導覽。
- 每一步指向畫面上實際存在的元素，附一句說明。說明卡片不遮住該元素。
- 每一步都有下一步、上一步、略過整個導覽。
- 走完或略過後，之後不再自動啟動。介面保留重新啟動導覽的入口。
- 某一步的目標元素不存在時，導覽跳過那一步，不中斷。
- 導覽不讀寫任何管理資料。

## 介面語言

- 後台提供中文（zh-TW）與英文（en）。
- 沒選過語言時，依瀏覽器語言決定：以 `zh` 開頭的用中文，其餘用英文。
- header 有語言切換：中文、英文、跟隨系統。切換立即生效，重新載入後維持。
- 語言選擇不影響 artifacts 的產出語言、CLI 輸出、稽核動作名稱，也不影響 server 回傳的錯誤訊息。

## 狀態顏色

- 正常、啟用、有效：綠色。
- 異常：紅色。
- 停權：琥珀色。
- 已撤銷：中性色，與有效態一眼可分。
- 一次性祕密的揭示橫幅（存取金鑰明文、邀請連結）：綠色成功樣式。
- 角色、稽核來源這類純資訊徽章：中性色。

## 版面與操作

- 所有操作都可用鍵盤完成。
- 視窗寬度至少 1024px 時，側欄固定顯示圖示與文字。更窄時側欄收起，用可見的按鈕開啟側邊面板。
- header 與側欄固定不動，只有主內容區捲動。
- 每一頁只有一個主要動作。
- 作業系統設定減少動態效果時，後台不播放轉場動畫。
