# 執行 OWASP / CWE 初步安全審查

本功能以 SpecLink 自有基本規則，對你授權的本機專案做初步檢查。不執行受檢程式、Shell 或套件指令，不上傳原始碼，也不需要 AI 或其他獨立掃描引擎。它會找疑似風險及未驗證項目，不能證明專案沒有漏洞。

內建基本掃描會保留。需要更深入的架構、業務授權與跨模組資料流檢查時，另行呼叫 `speclink-security-review` 技能；兩者是分開的檢查方式。深度技能只使用已準備的 `.security_kb/`、目前政策選定的標準與授權目標，不連網補資料、不執行專案腳本，也不自行擴查其他標準或版本。技能停用時不讀取目標來源；缺少必要政策快照、標準資料或指南時，會列為未驗證，不會給安全通過結論。

## 先完成兩項準備

1. 在專案設定 → 產出流程 → 產出政策開啟「啟用 OWASP / CWE 安全審查」，選範圍、標準、版本與審查項目後儲存。詳見[政策設定](policy-config.md)。
2. 到應用程式設定的「安全標準資料」，[安裝所選版本](security-data.md)。只選 Top 10 2025 時，其他標準可全部關閉。

深度審查還需要先把已安裝、且符合所選政策的資料準備成目標專案內的 `.security_kb/` 快照。準備動作只複製所選標準、對照及指南；缺資料時必須回到資料管理頁安裝或匯入，不會在審查時連線下載。

範圍的「關閉／不指定範圍」不等於主開關關閉，只是不自動限定 Web／API。主開關關閉時不讀受檢來源、不下載資料，結果為 DISABLED。主開關開著而所有標準關閉時，會顯示已啟用但未配置；明確選用的自有規則仍可執行，結果與標準對應分開。

## 在桌面 app 執行

開啟變更的 Verify 區，查看已選標準後，啟動基本規則審查。沒有既有 Verify 工單也能使用，不會為顯示安全資訊而建立工單或蓋章。進行中可看進度或取消；結束後在同一區[閱讀與匯出報告](security-report.md)。

資料缺失時，畫面會指出缺少的版本並提供前往資料管理的入口，不會自動下載。切換專案時，進度及結果仍屬開始執行的那個專案，不會串到另一個專案。

## 三種審查各看什麼

| 審查項目 | 看的內容與結果限制 |
| --- | --- |
| SDD 規格 | 提案、設計、規格、任務中的認證、授權、輸入限制、敏感資料、錯誤處理與安全驗收。缺少文字是安全要求缺漏或需人工確認，不是確認存在漏洞 |
| 原始碼基本規則 | Rust、TypeScript、JavaScript 的疑似硬編碼憑證、SQL 拼接、不安全 HTML、命令拼接、詳細錯誤直出及明顯不安全設定。JSON／YAML 補充設定檢查；其他語言保留未支援／未驗證 |
| API 與參數邊界 | 本機 OpenAPI 3.0／3.1 文件的空值、型別、長度、數字上下限、非法參數、授權與錯誤輸出。不呼叫 API，也不讀取外部引用 |

可以停用個別規則。文字比對只能提供疑似證據，不能可靠證實 SQL Injection、XSS 或其他漏洞可被利用。ASVS 沒有可用規則的要求會逐項未驗證，不會直接算通過；CWE 用於分類及說明。

## 審查哪些檔案

預設排除版本庫資料、套件相依、編譯與輸出目錄、自動生成標記檔及二進位資料。也能在政策中加入根相對的排除目錄；不能填絕對路徑、上層跳轉或磁碟代號。符號連結與特殊檔案不跟隨讀取，所有跳過都保留原因。

檢查限單檔1 MiB、總量100 MiB、10,000檔、目錄深度32、60秒；同一檔案的各類審查合計最多100筆疑似風險，總計最多10,000筆。超限、解析或讀取失敗會保留未驗證與未處理目標，不回安全通過。同一程序已有審查時，第二次啟動會顯示忙碌。

## Remote 專案先準備快照

Remote 的審查仍只讀你選定的本機副本。先明確執行準備操作，取得該專案、變更與副本相符的政策及 SDD 文件快照；只有這一步需要連線。準備成功後，實際審查不連網。報告會標記準備時間及政策版次，不宣稱知道遠端最新內容。

缺快照或沒有授權本機副本時，相關項目會顯示未驗證，不掃描其他專案、Server 目錄或快取。準備遇認證失效或斷線，舊快照保留，不自動改用另一個來源。

## CLI 操作與取消

將 CHANGE_NAME 換成變更名稱；指定目錄時，將 YOUR_PROJECT_DIRECTORY 換成授權的本機專案或 Remote 副本路徑。

```sh
speclink security rules
speclink security prepare --change CHANGE_NAME --root "YOUR_PROJECT_DIRECTORY"
speclink security run --change CHANGE_NAME --root "YOUR_PROJECT_DIRECTORY"
```

本機專案可直接執行審查；Remote 先執行準備，再離線執行審查。機器可讀輸出可加 `--json`，無色彩輸出可加 `--no-color`。選到不存在的變更、無效根目錄或壞設定會報錯，不會掃另一個目標。

Desktop 可取消，CLI 用 Ctrl+C；兩秒內回應並保存安全的部分報告。完整執行即使找到疑似風險仍以0結束；未完成或有未驗證項目以1結束，取消為130，指令語法錯誤為2。這些結果不新增封存門檻，既有[審查與驗證工單](quality-stations.md)仍各自運作。
