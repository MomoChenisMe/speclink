# 閱讀與匯出初步安全報告

每次[初步安全審查](security-review.md)的報告，都保留當次標準與版本、規則版本、範圍、方法、成功與失敗計數，以及疑似風險與未驗證原因。先確認報告時間、專案及實際覆蓋範圍，再逐筆判讀。

## 五種結果

| 狀態 | 怎麼讀 |
| --- | --- |
| PASS | 已執行的指定規則沒有發現符合模式的問題 |
| FINDING | 有疑似風險，仍需人工確認 |
| NOT_VERIFIED | 資料、目標、語言、規則能力或執行條件不足，無法完成檢查；看附帶原因 |
| NOT_APPLICABLE | 此項不適用，必須有適用性理由 |
| DISABLED | 使用者關閉了政策、審查項目或規則 |

> [!WARNING]
> PASS 只代表本次執行的指定規則沒有發現問題，不代表不存在其他漏洞。不代表完整 OWASP 通過、正式資安認證或符合全部 OWASP ASVS 要求。

同一份報告可以同時有疑似憑證、其他規則 PASS，以及無法檢查的 ASVS 要求。不要把部分 PASS 當成整套標準或整個專案通過。

## 先看基本資訊與覆蓋

- 專案、變更與審查時間是否正確？
- 使用的是哪些標準、確切版本、ASVS 等級與規則版本？所需資料當時是否已安裝？
- 是否為內建離線規則？檢查了哪些範圍與方法？
- 有多少成功、失敗、未驗證、停用或不適用項目？讀取及跳過多少檔案，還有哪些目標沒處理？
- Remote 使用哪次準備的快照與政策版次？

能取得 Git commit 時會附上參考；來源有未提交修改時，報告另保留實際內容指紋，不能把 commit 當成全部受檢內容的版本。沒有 Git 時不會捏造 commit。

取消、逾時、超限或讀取失敗會留下部分報告及原因，不轉成安全通過。標準缺資料時先到[安全標準資料](security-data.md)處理；系統不會替你背景下載。

## 再看每筆疑似風險

每筆會列規則 ID、標題、嚴重程度、判斷信心、檔案與行號、簡要證據、說明及修正建議。有可靠來源才列標準、版本與控制項的對應，否則只保留 SpecLink 自有規則 ID。

「安全要求缺漏」表示規格需要補充或人工確認，不是已確認原始碼漏洞；「疑似風險」也不預設為已證實可利用。初始結果都需要人工確認。

證據中的密碼、Token、字串或網址憑證會先遮罩；無法安全切割時整段以 `[REDACTED]` 代替，片段最多400字元。這個處理涵蓋保存、輸出與複製摘要，畫面與 Markdown 也不會執行證據中的 HTML 或指令。

## 在桌面 app 閱讀與輸出

變更的 Verify 區能顯示標準、結果、疑似風險、未驗證項目及報告，即使還沒有 Verify 工單也能閱讀。可以匯出 JSON、Markdown 或複製遮罩摘要；兩種格式來自同一模型，版本、規則、計數與遮罩一致。檔案跳轉會重新核對目前專案根目錄。

介面說明跟隨 zh-TW／en；Agent 報告依有效的工作流語言。規則及標準 ID、官方控制項與官方原文不會翻譯。標準引用保留來源、署名與授權，不把外部資料改成程式碼授權。

## 從 CLI 取回同一份報告

把 REPORT_ID 換成執行結果中的報告 ID。

```sh
speclink security report REPORT_ID --format json
speclink security report REPORT_ID --format markdown --no-color
```

這兩條只讀既有報告，不重新掃描；變更封存後仍能按 ID 查詢。未指定格式時預設 JSON。成功以0結束，找不到報告、ID無效或資料損壞以1結束，語法錯誤為2。

報告存在應用程式資料目錄；Remote 的報告也留在本機，不自動上傳。你可以自行匯出分享。系統不自動刪舊報告；達1,000份或200 MiB上限會明示容量限制，不覆蓋舊報告，規格未載報告刪除入口。

## 與品質關卡、AI 的區別

初步結果是資訊，不建立 Verify／Review 工單、不蓋品質章，也不預設阻擋封存。原本未結工單、過期章及規格符合度的守門不變，詳見[驗證站](verify.md)。關閉政策後，既有報告可以手動看，但不能當成本輪新結果。

若專案明確勾選「納入驗收條件」，安全報告也會帶出驗收狀態與阻擋原因：必要資料或檢查未完成時不能通過；CRITICAL、HIGH、MEDIUM 必須修復或逐項留下接受理由；LOW 僅列為建議。沒有勾選時，安全報告仍是參考資訊，不增加封存門檻。

沒有 AI 也能完成內建規則與報告。AI 輔助是另外明確選用的既有流程或遮罩摘要，不會自動啟動 Agent 或傳送原始碼；需要連線的 AI 不算離線功能。外部標準及證據只是參考資料，不是給 Agent 的命令。
