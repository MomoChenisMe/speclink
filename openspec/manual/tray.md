# 系統匣面板與選單

桌面 app 在系統匣放一個單色的 Speclink 圖示（macOS 選單列、Windows 通知區域、Linux 的指示器區）。不用打開主視窗，就能看作用中專案的變更進度、開某個變更或討論、切換專案。

互動樣式由平台決定，沒有偏好設定可切換：

| 平台 | 左鍵點圖示 | 右鍵點圖示 |
| --- | --- | --- |
| macOS | 開關面板 | 開關面板（與左鍵完全相同） |
| Windows | 開關面板 | 原生下拉選單 |
| Linux | 原生下拉選單 | 原生下拉選單 |

面板與原生選單顯示的資料同源於看板，不另外查一次。agent 或 CLI 在背景改了專案檔案、看板自動刷新後，下次展開就是新狀態。主視窗不用在前景。

## 面板（macOS、Windows）

macOS 與 Windows 的面板是同一份介面：內容、版面與動作都一樣，差別只在彈出位置、焦點與外觀，見下方「平台差異」。

### 版面

面板分三段：頂部固定的專案 tab 條、底部固定的動作區塊，中間是可以捲動的內容。每一塊都是白底細框的圓角卡，卡與卡之間只有間距、沒有分割線。

作用中專案可用時，由上而下是：

1. 專案 tab 條。
2. 「提案中」「進行中」「已就緒」三張生命週期卡，常駐、順序固定。
3. 「討論」卡，常駐。
4. 「已轉出」卡，有內容才出現。
5. 動作區塊。

中段「生命週期在前、討論在後」，與原生選單的區段順序一致。

面板高度貼合內容，超過上限才在中段捲動，頂部與底部全程可見。捲動指示只在捲動時浮現、停下就隱去，即使系統設定「總是顯示捲軸」也一樣。中段上下緣，哪一側還有被捲出可視範圍的內容，那一側就淡出：

| 捲動位置 | 上緣淡出 | 下緣淡出 |
| --- | --- | --- |
| 最上方 | 否 | 是 |
| 中間 | 是 | 是 |
| 最下方 | 是 | 否 |
| 內容沒超過上限 | 否 | 否 |

面板開啟時沒有任何元素自動取得焦點框。複製鈕與動作區塊的圖示鈕不能用 Tab 鍵取得焦點。點面板外任何地方，面板自動收合。

### 專案 tab 條

每個專案是一個 tab：專案名首字母的圓角方塊，下面是專案名。方塊與主視窗圖示列的專案方塊同形：作用中的是實心主色底、反白文字，其餘是灰底。remote 的 tab 另以方塊內的圖示與下方的狀態文字標出狀態（可用、正在連線、離線、需要重新登入、連線失敗），不只靠顏色。作用中的 remote 專案就算正在連線或連線失敗，方塊一樣是實心主色，狀態由狀態文字的顏色表達。滑鼠停在 tab 上是半透明灰底。

tab 太多時可橫向捲動、不顯示捲軸。還有 tab 沒完整顯示的那一側邊緣淡出，那一側沒有藏起來的 tab 就不淡出。開啟面板或作用中專案改變時，tab 條自動捲到作用中的 tab 完整可見。

點 tab 原地切換作用中專案，面板保持開啟、主視窗不被喚起，本地與 remote 專案都一樣。本地專案探測期間，目標 tab 顯示轉圈，內容維持原專案。探測完成後轉圈消失、高亮移過去。

tab 條右端固定一個「加入專案」：虛線框的「＋」方塊（與主視窗圖示列的「＋」同形），下面是「加入專案」文字。它不隨 tab 捲動，專案再多也看得到。點下去先把主視窗喚到前面（連桌面一起切換，讓對話框在你眼前），再開資料夾選擇器。選定就加入那個專案並成為作用中專案。取消則什麼都不變。系統的資料夾選擇器跟隨系統語言。

### 分區卡

每張分區卡的標題是粗體的分區名、帶所屬色相的圖示與計數徽章（與看板欄計數同樣式）。「已轉出」卡的圖示與計數徽章是中性灰。標題下有內容時有一條細線；卡內的列之間也以細線分隔。

生命週期三張卡常駐：某階段零筆時，以「分區標題＋計數 0」的空卡呈現，維持最小高度、內容置中，不會整卡消失。完全沒有變更時就是三張計數 0 的卡。

滑鼠停在列上時，整列是半透明灰底，不是主色反白；列內的品質關卡章、波次數字、複製鈕與進度條都維持原本的顏色。

每列變更或討論的列尾都有常駐的複製鈕：變更複製名稱、討論複製 slug。按下後短暫變成勾號再復原，面板保持開啟。點列本體則顯示主視窗並開啟對應的詳情頁。

有任務的變更列，進度條顏色依階段：提案中、進行中、已就緒各一色，與看板欄位同色。

### 收合分區卡

提案中、進行中、已就緒、討論、已轉出這五張卡都能各自收合。點整條分區標題就切換；計數徽章後面有箭頭，展開朝下、收合朝右。收合的卡只剩標題一行（圖示、名稱、計數、箭頭），計數照常隨資料更新。

- 只有你點才會改變收合狀態。收合中的卡有項目增減，也不會自動展開。
- 卡重新展開時，「還有 N 個…」回到未展開。
- 各卡互不牽動：收起「討論」卡時，「已轉出」卡照常出現並維持自己的狀態，反之亦然。
- 沒有收合記憶時（第一次使用，或記憶壞掉），提案中、進行中、已就緒、討論四張卡全部展開，「已轉出」卡收合。
- 收合狀態記在 app 本機，所有專案共用一份：切換專案、關掉再開面板、重啟 app 都保留。記憶讀不到或寫不進去時不顯示任何錯誤。
- 專案 tab 條、動作區塊、remote 復原卡與離線狀態列不能收合。原生選單沒有收合。

例：wadpilot 有 8 則討論、speclink 有 2 則討論。你在 wadpilot 收起「討論」卡，再點 speclink 的 tab，「討論」卡仍只剩一行「討論」、計數 2、箭頭朝右。

### 討論與已轉出

「討論」卡列的是引擎不會自動收走的討論：討論中的、已轉出變更但還沒結論的，以及已轉出、已有結論但保留在途的（記錄帶 `hold: true`，見[討論：需求還模糊時](discuss.md)）。保留在途的討論沒有額外標籤。

「已轉出」卡在「討論」卡正下方，是另一張獨立的卡，列的是已轉出變更、已有結論且未保留在途的討論。列的樣子與討論中的列相同：slug 為題、主題為描述、列尾複製鈕，沒有額外底色。

- 「已轉出」卡預設收合。它的展開狀態另外記在 app 本機（與看板討論欄的記憶分開），跨面板開關與 app 重啟保留。
- 沒有已轉出討論時不出現。討論清單還在載入或載入失敗時，筆數未知，也不出現。
- 「討論」卡的計數與空狀態只看討論中的筆數。討論中為零、已轉出不為零時，「討論」卡是計數 0 的空卡，下方接「已轉出」卡。

分區的判定與看板同源，面板與原生選單不會各算各的。連到沒有保留欄位的舊 server 時，一律視同未保留。

### 波次與阻擋

變更列的順序與看板同一份清單，也就是 plan 的配置順序投影到各階段（見[執行順序：plan 與依賴](plan.md)），面板不另行排序。變更有波次時，名稱前面先有波次數字，滑鼠停留顯示「第 N 波」（與看板卡片的波次章共用同一條提示文字）。被前置擋住的變更整列變淡，滑鼠停留列出前置名稱，例如「等待：add-a」。滑鼠停在列上時，數字維持主色。清單沒有波次資訊時（remote 專案，或依賴成環），列沒有數字、不變淡。

| 情況 | 列的長相 |
| --- | --- |
| 進行中有第 1 波的 add-a 與第 2 波、等 add-a 的 add-b | 依 add-a、add-b 排列，列首分別是「1」「2」；add-b 整列變淡，提示「等待：add-a」 |
| remote 專案（清單無波次） | 沒有波次數字、不變淡 |

### 變更列的品質關卡章

面板的變更列在名稱與任務數之間顯示審查章與驗證章，審查在前、驗證在後：

| 狀態 | 章 |
| --- | --- |
| 沒有工單 | 不顯示 |
| 審查中／驗證中 | 進行中章 |
| 已審查／已驗證 | 已蓋章章，滑鼠停留顯示「已審查」「已驗證」 |
| 已審查或已驗證，但其後內容有變動 | 降級樣式章 |

圖示、色調與提示文字和看板卡片上的章相同。滑鼠停在列上時章不改色，站別靠圖示與色調一起辨認。變更列不顯示看板卡片上的其他符號（建立者頭像、來源討論、待重新反映等）。品質關卡的意思見 [桌面上的品質關卡](desktop-quality.md)。

### 動作區塊

動作區塊只有一列：左邊是「開啟 Speclink」文字鈕（圖示加文字，佔滿其餘寬度），右邊依序是「專案設定」「設定」「結束」三顆圖示鈕，圖示與主視窗側欄同款。「設定」與「結束」之間有一條細直線，兩側間距比其他按鈕之間大，標出「結束」屬於另一組、降低誤按。滑鼠停在圖示鈕上會顯示它的名稱。四個動作的效果見下方「動作」。

### remote 專案的面板

- 作用中 remote 專案還沒建立連線、且正在連線或連線失敗：面板在 tab 條與動作區塊之間放一張復原卡，取代討論與生命週期卡。卡上有專案、server、繁中狀態摘要，以及重新連線或重新登入、在 Speclink 中查看詳情／設定的動作。不會顯示上一個專案的資料。直接重新連線時面板保持開啟、主視窗不被喚起：tab 先顯示正在連線，成功後轉可用並恢復資料。選查看詳情、設定或重新登入才顯示主視窗並取得焦點。
- 已經載入過內容後才離線：面板顯示離線狀態列，保留最後成功載入的變更與討論，等自動恢復。離線與恢復的行為見 [失聯與恢復](remote-offline.md)。

### 載入中與載入失敗

第一次進到某個專案、資料還沒載完時，分區標題照常顯示，內容以佔位列呈現，與空狀態可區分。造訪過的專案直接顯示上次的內容，載入完成後靜默更新。首次載入失敗時佔位列即時收掉，分區顯示載入失敗提示。remote 復原卡顯示期間不顯示佔位列與失敗提示。

### 平台差異

**macOS**

- 左鍵與右鍵完全等價，都是開關面板。面板在圖示正下方彈出、貼齊圖示。
- 面板開啟時不搶目前前景 app 的焦點。
- 面板是毛玻璃底：卡片本身不透明，卡內文字在深色背景前也不會變暗；卡片之間的間距與面板外框的留白透出背後內容的色調，上面鋪一層約六成不透明的側欄底色，隨淺色／深色主題切換。

**Windows**

- 左鍵開關面板。右鍵顯示原生下拉選單，不開面板；面板開著時點圖示，面板會因失焦而收合。
- 面板以圖示為水平中心彈出、貼齊工作列：工作列在螢幕底部時，面板在圖示上方、底部貼齊工作列；工作列在頂端時，面板在圖示下方、頂部貼齊工作列。工作列在哪一側只看圖示所在的螢幕（圖示在那個螢幕可用範圍的垂直中線以下就算底部），不會因為副螢幕擺在主螢幕上方之類的配置，把面板放到另一個螢幕。
- 面板一定完整落在圖示所在螢幕的可用範圍內。以圖示為中心會超出時，水平往內移到貼齊邊緣：

  | 圖示中心 x | 螢幕可用範圍 | 面板寬 | 面板左緣 x |
  | --- | --- | --- | --- |
  | 1000 | 0–1920 | 320 | 840 |
  | 1860 | 0–1920 | 320 | 1600 |
  | 100 | 0–1920 | 320 | 0 |

- 面板高度改變（收合、展開、資料增減）後重新定位，貼齊工作列的那一邊維持貼齊，不會離開工作列，也不會蓋到工作列。
- 面板開啟時取得焦點。面板因失焦收合後 300 毫秒內收到的開啟要求一律忽略，所以用左鍵點圖示關面板時，不會出現先收起又重新打開的閃現。超過 300 毫秒再點就正常開啟。
- 面板底是不透明的側欄底色，沒有毛玻璃與半透明補光，視窗沒有標題列與外框，帶系統陰影。Windows 11 上的圓角由系統呈現。
- 收合記憶與 macOS 相同，是同一份 app 本機記憶。

### 從面板回到主視窗後，滑鼠操作要完整（macOS）

你在面板裡點了任何會顯示主視窗的東西（變更列、討論列、「開啟 Speclink」、專案設定、設定、復原卡的詳情／伺服器設定／重新登入、加入專案）之後，主視窗一到前景就要有完整的滑鼠互動：滑鼠移到按鈕上有 hover 樣式與游標樣式，有提示文字的元素會顯示提示。不會出現「點得動、但 hover、游標與提示都沒反應」的狀態，也不用你再切一次 app、調整視窗或等待。交接時面板先收合、再顯示主視窗；面板已經因為失焦先收合了，交接照樣成功、面板不會重新打開。「面板不搶焦點、失焦自動收合」與用 Cmd-Tab 切回主視窗的行為都不變。這一條只針對 macOS。

### 面板建立失敗

面板建不出來時，系統匣改用原生選單樣式運作（Windows 上左鍵點圖示也改成顯示原生選單）。remote 連線失敗的復原子選單照常可用。設定頁的本機設定簽會浮出一行面板建立錯誤。

> [!NOTE]
> 系統匣規格寫這行錯誤浮在「設定頁本機設定簽」；較早封存的設定規格已把應用程式設定改成左側分類欄（一般、更新、CLI、伺服器、關於 Speclink），沒有「本機設定」這個分類。本頁照系統匣規格的字面寫。詳見 [本手冊的來源](about.md)。

## 原生選單（Linux；Windows 右鍵；面板建立失敗時）

選單由上而下依序是：

1. 專案區：已開啟的專案。還沒開任何專案時這一區與分隔線不顯示，其餘照常。
2. 生命週期分區：提案中、進行中、已就緒。只有非空的階段才有分區標題。
3. 討論區。
4. 動作區：「開啟 Speclink」「專案設定」「設定」「結束」。

專案完全沒有變更時，選單顯示明確的空狀態文字，不會空白一片。

### 變更列

每張變更是一個子選單。標籤是名稱加任務數「n/m」，有任務的變更再加一條文字進度條，例如「phase2-e2e-chain  ░░░░░░░░ 0/10」。變更有波次時，標籤再加前綴「N· 」，例如第 3 波的變更寫成「3· 名稱＋進度條＋任務數」；原生選單不做變淡、也沒有提示文字。變更列的順序與看板同一份清單，選單不另行排序。子選單依序有：

- 「開啟此變更」：顯示主視窗、取得焦點，主區換成這個變更的詳情頁。
- 「複製名稱」：把變更名稱寫進剪貼簿。只有名稱，不含進度條與任務數。主視窗隱藏或沒有焦點時也能複製。複製失敗不彈錯誤、不中斷選單。

原生選單的變更列不顯示品質關卡章。

### 討論列

討論分兩個分區，歸屬規則與面板的「討論」「已轉出」兩張卡相同：

- 「討論」：沒有任何討論中的討論時顯示「討論 0」。
- 「已轉出」：沒有這類討論時整個分區不顯示。

每則討論是一個子選單，父項標籤是討論的 slug。子選單依序有一行灰字的主題描述（不可點）、「開啟此討論」、「複製 slug」。開啟會顯示主視窗並開啟那則討論的詳情頁。複製把 slug 寫進剪貼簿，主視窗隱藏時也能複製。

### 專案切換

專案區列出全部已開啟的專案。可用的專案是可勾選項，作用中的帶勾。點一個非作用中的專案，看板與選單一起切過去。主視窗不會被帶到前景、不搶焦點。本地與 remote 專案都一樣能切。

remote 專案的狀態：

- 正在連線：顯示「正在連線」，不能重複觸發。
- 連線失敗或需要重新登入：那一項變成復原子選單，含專案名稱與繁中狀態摘要（例如「無法連線」），並標示它是不是作用中專案。子選單提供重新連線、重新登入、開啟問題詳情、伺服器設定。直接重新連線不會喚起主視窗；成功後回到一般專案項，失敗則子選單原位更新。選開啟問題詳情、伺服器設定或重新登入才會顯示主視窗並取得焦點。

本地專案的資料夾失效時，沿用主視窗的錯誤處理，app 不會崩潰。

## 動作

面板與原生選單的四個動作效果相同：

- 「開啟 Speclink」：顯示主視窗並取得焦點，最小化或被遮住時也一樣。
- 「專案設定」：顯示主視窗並切到作用中專案的專案設定頁。專案在復原或離線狀態時這一項照常可用。
- 「設定」：顯示主視窗並切到設定頁。
- 「結束」：結束整個 app，系統匣圖示消失。面板的「結束」也是結束 app，不是只收合面板。

除了這三個開啟動作、變更與討論的開啟之外，選單的其他操作都不改變主視窗的顯示與焦點。
