# 系統匣選單

桌面 app 在系統匣放一個單色的 Speclink 圖示（macOS 選單列、Windows 通知區域、Linux 的指示器區）。不用打開主視窗，就能看每個專案的變更進度、開某個變更或討論、切換專案。

互動樣式由平台決定，沒有偏好設定可切換：

- macOS：點圖示彈出面板。
- Windows 與 Linux：點圖示展開原生下拉選單。

兩者顯示的資料同源於看板。agent 或 CLI 在背景改了專案檔案、看板自動刷新後，下次展開選單就是新狀態。主視窗不用在前景。

## 原生選單（Windows、Linux）

選單由上而下依序是：

1. 專案區：已開啟的專案分頁。還沒開任何專案時這一區與分隔線不顯示，其餘照常。
2. 生命週期分區：提案中、進行中、已就緒。只有非空的階段才有分區標題。
3. 討論區。
4. 動作區：「開啟 Speclink」「專案設定」「設定」「結束」。

專案完全沒有變更時，選單顯示明確的空狀態文字，不會空白一片。

### 變更列

每張變更是一個子選單。標籤是名稱加任務數「n/m」，有任務的變更再加一條文字進度條，例如「phase2-e2e-chain  ░░░░░░░░ 0/10」。子選單依序有：

- 「開啟此變更」：顯示主視窗、取得焦點，並開啟這個變更的詳情。
- 「複製名稱」：把變更名稱寫進剪貼簿。只有名稱，不含進度條與任務數。主視窗隱藏或沒有焦點時也能複製。複製失敗不彈錯誤、不中斷選單。

原生選單的變更列不顯示品質關卡的章。

### 討論列

討論分兩個分區：

- 「討論」：還沒有結論的討論，包含討論中的，以及已轉出變更但還沒結論的。沒有任何討論時顯示「討論 0」。
- 「已轉出」：已轉出變更且已有結論的討論。沒有這類討論時整個分區不顯示。

每則討論是一個子選單，父項標籤是討論的 slug。子選單依序有一行灰字的主題描述（不可點）、「開啟此討論」、「複製 slug」。開啟會顯示主視窗並開啟那則討論。複製把 slug 寫進剪貼簿，主視窗隱藏時也能複製。

### 專案切換

專案區列出全部已開啟的分頁。可用的專案是可勾選項，作用中的帶勾。點一個非作用中的專案，看板與選單一起切過去。主視窗不會被帶到前景、不搶焦點。本地與 remote 專案都一樣能切。

remote 專案的狀態：

- 正在連線：顯示「正在連線」，不能重複觸發。
- 連線失敗或需要重新登入：那一項變成復原子選單，含工作區名稱與繁中狀態摘要（例如「無法連線」）。子選單提供重新連線、重新登入、開啟問題詳情、伺服器設定。直接重新連線不會喚起主視窗；成功後回到一般專案項，失敗則子選單原位更新。選開啟問題詳情、伺服器設定或重新登入才會顯示主視窗並取得焦點。

本地專案的資料夾失效時，沿用主視窗分頁的錯誤處理，app 不會崩潰。

### 動作區

- 「開啟 Speclink」：顯示主視窗並取得焦點，最小化或被遮住時也一樣。
- 「專案設定」：顯示主視窗並切到作用中專案的專案設定頁。工作區在復原或離線狀態時這一項照常可用。
- 「設定」：顯示主視窗並切到設定頁。
- 「結束」：結束整個 app，系統匣圖示消失。

除了這三個開啟動作、變更子選單與討論項之外，選單的其他操作都不改變主視窗的顯示與焦點。

## 面板（macOS）

點系統匣圖示，圖示下方彈出貼齊的面板。再點一次收合。左鍵與右鍵完全等價。面板開啟時不搶目前前景 app 的焦點，點面板外任何地方就自動收合。面板裡沒有任何元素會自動取得焦點框。

面板有三段：頂部的專案分頁條與底部的動作區固定不動，中間的內容區可以捲動。面板高度貼合內容，超過上限才在中段捲動。捲動指示只在捲動時浮現、停下就隱去，即使系統設定「總是顯示捲軸」也一樣。

### 專案分頁條

每個專案是一個 tab：專案名首字母的圓角方塊加專案名。作用中的 tab 是實心主色底、反白文字。remote 的 tab 另以圖示與文字標出狀態（可用、正在連線、離線、需要重新登入、連線失敗），不只靠顏色。tab 太多時可橫向捲動、不顯示捲軸。

點 tab 原地切換作用中專案，面板保持開啟、主視窗不被喚起。本地分頁探測專案期間，目標 tab 顯示轉圈，內容維持原專案。探測完成後轉圈消失、高亮移過去。

分頁條尾端有「加入專案」：點下去先把主視窗喚到前面（連桌面一起切換，讓對話框在你眼前），再開資料夾選擇器。選定就以分頁加入並成為作用中專案。取消則什麼都不變。系統的資料夾選擇器跟隨系統語言。

### 內容區

作用中專案可用時，內容由上而下是：

1. 討論區塊：「討論」分區常駐，「已轉出」分區有內容才出現。
2. 生命週期區塊：「提案中」「進行中」「已就緒」三張分區卡常駐，順序固定。某階段零筆時以「分區標題＋計數 0」的空卡呈現，不會整卡消失。完全沒有變更時就是三張計數 0 的卡。
3. 動作區塊：「開啟 Speclink」「專案設定」「設定」「結束」。面板的「結束」一樣結束整個 app，不是只收合面板。

每個分區是一張半透明圓角卡，標題帶主色圖示與項目計數徽章。這個順序（討論在前、生命週期在後）與原生選單刻意不同。

每列變更或討論的列尾都有常駐的複製鈕，複製內容與原生選單一致：變更複製名稱、討論複製 slug。按下後短暫變成勾號再復原，面板保持開啟。點列本體則顯示主視窗並開啟對應詳情。

有任務的變更列，進度條顏色依階段深淺：提案中最淺、進行中次之、已就緒最深，與看板欄位同一階梯。

### 面板變更列的品質關卡章

面板的變更列在名稱與任務數之間顯示審查章與驗證章，審查在前、驗證在後：

| 狀態 | 章 |
| --- | --- |
| 沒有工單 | 不顯示 |
| 審查中／驗證中 | 進行中章 |
| 已審查／已驗證 | 已蓋章章，滑鼠停留顯示「已審查」「已驗證」 |
| 已審查或已驗證，但其後內容有變動 | 降級樣式章 |

圖示、色調與文字和看板卡片上的章相同。滑鼠停在列上時列反白為主色底，章跟著改成前景色，這時靠圖示形狀分辨站別。變更列不顯示看板卡片上的其他符號（建立者頭像、來源討論、待重新反映等）。品質關卡的意思見 [桌面上的品質關卡](desktop-quality.md)。

### remote 專案的面板

- 作用中 remote 專案還沒建立連線、且正在連線或連線失敗：面板用一張復原卡取代討論與生命週期區塊。卡上有工作區、server、繁中狀態摘要，以及重新連線或重新登入、在 Speclink 中查看詳情／設定的動作。不會顯示上一個專案的資料。直接重新連線時面板保持開啟、主視窗不被喚起：tab 先顯示正在連線，成功後轉可用並恢復資料。選查看詳情、設定或重新登入才顯示主視窗。
- 已經載入過內容後才離線：面板顯示離線狀態列，保留最後成功載入的變更與討論，等自動恢復。離線與恢復的行為見 [失聯與恢復](remote-offline.md)。

### 載入中與載入失敗

第一次進到某個專案、資料還沒載完時，分區標題照常顯示，內容以佔位列呈現，與空狀態可區分。造訪過的專案直接顯示上次的內容，載入完成後靜默更新。首次載入失敗時佔位列即時收掉，分區顯示載入失敗提示。remote 復原卡顯示期間不顯示佔位列與失敗提示。

### 面板建立失敗

macOS 上面板建不出來時，系統匣改用原生選單樣式運作。remote 連線失敗的復原子選單照常可用。設定頁的本機設定簽會浮出一行錯誤。

## 分區太長時

每個分區（生命週期各階段、討論、已轉出）直接列前 5 筆。第 6 筆起收進分區尾端的「還有 N 個…」。原生選單裡它是子選單，內含其餘項目，每項仍有完整的子選單動作。面板裡它是可展開列，點一下展開、再點收合。5 筆以內不出現這個節點。

| 分區項目數 | 直列 | 溢出節點 |
| --- | --- | --- |
| 5 | 5 | 無 |
| 6 | 5 | 還有 1 個… |
| 20 | 5 | 還有 15 個… |
