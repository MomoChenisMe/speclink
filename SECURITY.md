# Security Policy

## Supported versions

Only the latest release gets security fixes. Before you report a problem, check that it occurs in the [latest release](https://github.com/MomoChenisMe/speclink/releases/latest).

## Report a vulnerability

Do not report a vulnerability in a public issue, a pull request, or a discussion.

Report it privately on GitHub:

1. Go to the [Security tab](https://github.com/MomoChenisMe/speclink/security) of this repo.
2. Click **Report a vulnerability**.
3. Fill in the form.

Tell us:

- The affected part: the CLI, the desktop app, the server, the Node SDK, or the Claude Code plugin.
- The version (`speclink --version`) and your operating system.
- The steps that show the problem, and what an attacker can do with it.

Do not put real access tokens, passwords, or data from your own systems in the report.

## What happens next

- We reply in the private report.
- We work on a fix there with you.
- When the fix is released, we publish a security advisory. We credit you unless you ask us not to.
